
# Week 2 Reflection – Power BI  

## 🚀 What I Built  
During Week 2, I focused on building interactive Power BI dashboards using my banking dataset.  

I created:  
- A proper data model with relationships  
- Multiple report pages for different insights  
- KPI cards (Total Transactions, Loan Amount, Customers)  
- Interactive visualizations (Bar charts, Line charts, Pie charts, Tables)  
- Slicers (Date, Region, Category)  
- Drill-down features and tooltips  
- Report-level filters  

The final result was a fully interactive Power BI dashboard that allows dynamic data exploration.

---

## 📚 Key Learning  
- Understanding data modeling and relationships in Power BI  
- Difference between calculated columns and measures  
- Writing basic DAX measures  
- Importance of clean and structured data  
- Using slicers and filters effectively  
- Improving dashboard design and user experience  

---

## ⚠️ One Weak Area  
- Writing advanced DAX formulas  
- Optimizing data models for performance  
- Creating more professional and consistent dashboard designs
